## Direction contract

THESIS: Refuses the generic SaaS-dashboard rut (rounded cards, soft shadows, purple gradients) — this console is one instrument panel an operator trusts with real infrastructure, not a set of pretty pages.

OWN-WORLD: Matte graphite canvas (not pure black); a restrained functional grammar — teal is the only interactive/nominal accent, amber is caution, red is reserved for destructive actions only, never decorative or glowing. Hairline dividers and engraved-label typography replace glassy shadows/glow. Light theme is a daylight-ops variant: paper-white ground, ink-dark text, same three functional colors. Monospace for identifiers/status/logs; humanist sans for prose and labels.

STORY: The operator lands on one instrument bank of live project channels, drills into a module through a proportional grouped tab rail, edits inline in place, and trusts every risky action because state is always unambiguous.

FIRST VIEWPORT: Fixed left tab rail grouping the console's sections by proportion; the main pane is a channel-row instrument bank, one row per project, showing live health/volume/actions — no KPI cards.

FORM: Operations Control Room, assigned index 4 of the grounded direction list, seed key fcf29c5e.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
