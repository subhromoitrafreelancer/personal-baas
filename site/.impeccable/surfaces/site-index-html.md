# Surface brief: Stead marketing site (site/)

Scope: Persuade. Home, Article, Contact. Static HTML/CSS/JS plus PHP form handler. Code-led build.
Audience: solo devs and small teams; agencies second. Actions: GitHub repo, contact form.
Constraints: no "Supabase/Firebase/clone"; no invented metrics; client work anonymized; Apache-2.0 badge only after LICENSE is committed.
Unresolved: tagline wording.

## Direction contract

THESIS: The page is one surveyed plat of your backend: projects are lots, schema boundaries are fence lines, the compose stack is the title block. Refuses the headline-over-subcopy-plus-feature-card-grid template.
OWN-WORLD: Linen plat paper (#f1ece0), deep green survey ink (#1d3b34), rust (#a8431f) only for the primary action and the active lot, near-black body. Hairline linework, bearing-and-distance labels, a title block, lot numbers. Draughtsman lettering for labels, a plain readable face for prose; no default-list fonts. Recognisable with all copy removed: ruled lots, boundary dashes, north arrow, title block.
STORY: A visitor sees their own backend as a parcel they own, understands the capabilities sit inside it, believes it because the ATS app and feature list are real, and either opens GitHub or writes via the survey-request form.
FIRST VIEWPORT: Large plat spanning the viewport width on desktop with three labelled lots (project schemas) containing capability labels (auth, storage, functions, PDF, scheduler, vault); title block bottom-right holds the one-line pitch, the install command, the rust GitHub button and a plain Talk-to-me link; Stead wordmark and north arrow top-left. Mobile: lots stack vertically, title block follows.
FORM: Survey Plat, pick card, position 1 on my ordered list, seed key b4b6110c.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
